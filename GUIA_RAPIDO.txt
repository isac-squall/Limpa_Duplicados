🚀 GUIA RÁPIDO - LIMPEZA DE DUPLICADOS
========================================

📌 RESUMO EM 10 SEGUNDOS:

Você tem um executável pronto para usar!
Não precisa instalar NADA!
Duplo clique e pronto!


✅ COMO USAR - PASSO A PASSO
═════════════════════════════════════════════════════════════════════════════

PASSO 1️⃣ : Localize o arquivo
├─ Caminho: dist/
├─ Nome: Limpa_Pedidos_Base_Pedidos.exe
└─ Ação: Duplo clique nele


PASSO 2️⃣ : Aguarde alguns segundos
├─ Você verá uma janela preta (console)
├─ Mostrará mensagens como "Limpeza de duplicados"
├─ Aguarde 3-5 segundos
└─ Não feche nada ainda!


PASSO 3️⃣ : Navegador abre automaticamente
├─ Seu navegador padrão vai abrir
├─ Verá o logo 📦 no topo
├─ Se não abrir: acesse http://localhost:8501 manualmente
└─ Pronto! A aplicação está rodando


PASSO 4️⃣ : Carregue seu arquivo Excel
├─ Clique em "📂 Carregue a planilha de pedidos"
├─ Selecione arquivo .xlsx
├─ IMPORTANTE: Arquivo PRECISA ter aba "BASE_PEDIDOS"
└─ Arquivo carrega e mostra preview


PASSO 5️⃣ : Escolha as configurações
├─ Você verá "⚙️ Configuração da análise"
├─ Escolha qual coluna usar:
│  ├─ Coluna A (padrão)
│  └─ Coluna R (se disponível no seu Excel)
├─ Escolha como tratar duplicados:
│  ├─ Manter o primeiro
│  ├─ Manter o último
│  ├─ Remover todos
└─ Escolha uma das 3 opções


PASSO 6️⃣ : Clique em "Analisar e limpar duplicados"
├─ Botão verde no meio da tela
├─ App começa a processar
├─ Aguarde (deve ser rápido)
└─ Resultado aparece automaticamente


PASSO 7️⃣ : Veja os resultados
├─ Números no topo mostram:
│  ├─ Registros originais
│  ├─ Pedidos duplicados
│  └─ Registros finais
├─ Tabela "🔴 Pedidos duplicados" mostra o que foi removido
├─ Tabela "🟢 Base final" mostra resultado limpo
└─ Se sem duplicados: mensagem especial "NENHUMA DUPLICATA ENCONTRADA"


PASSO 8️⃣ : Baixe seu arquivo Excel
├─ Clique em "⬇️ Baixar Excel com auditoria completa"
├─ Arquivo baixa com nome: Pedidos_BASE_PEDIDOS_Auditoria.xlsx
├─ Contém 2 abas:
│  ├─ Base_Limpa (resultado final)
│  └─ Duplicados_Encontrados (o que foi removido)
└─ Pronto! Use este arquivo normalmente

⚠️ IMPORTANTE - REQUISITOS DO ARQUIVO EXCEL
═════════════════════════════════════════════════════════════════════════════

SEU ARQUIVO EXCEL PRECISA TER:

✅ OBRIGATÓRIO:
└─ Uma aba chamada exatamente: "BASE_PEDIDOS"

✅ RECOMENDADO:
├─ Coluna A com dados (números de pedido, etc)
└─ Coluna R com NF (número de nota fiscal)

❌ NÃO É OBRIGATÓRIO:
├─ Outras abas (app ignora)
├─ Outras colunas (app não usa)
├─ Formatação especial
└─ Nenhuma ordem específica


■ EXEMPLO DE ARQUIVO VÁLIDO:

BASE_PEDIDOS:
├─ Coluna A (Número Pedido): 001, 002, 001 (DUPLICADO!)
├─ Coluna B (Cliente): João, Maria, João
├─ Coluna C (Valor): 100, 200, 100
├─ Coluna R (NF): 1234, 5678, 1234

Resultado: 1 duplicata encontrada (linha da cópia de "001")

🎯 CENÁRIOS DE USO
═════════════════════════════════════════════════════════════════════════════

CENÁRIO 1: Análise por Coluna A (Padrão)
├─ Use quando: Quer remover duplicatas por número do pedido
├─ Resultado: Mantém 1 pedido, remove repetidas
└─ Exemplo: Pedidos 001, 002, 001 → Fica 001, 002


CENÁRIO 2: Análise por Coluna R (NF)
├─ Use quando: Quer remover duplicatas por nota fiscal
├─ Resultado: Mantém 1 NF, remove repetidas
└─ Exemplo: NF 1000, 2000, 1000 → Fica 1000, 2000


CENÁRIO 3: Sem Duplicados (Verificação)
├─ Use quando: Quer apenas verificar se tem duplicatas
├─ Resultado: Mensagem "NENHUMA DUPLICATA ENCONTRADA"
└─ Exemplo: Todos únicos → 0 duplicatas

🔧 SOLUÇÃO RÁPIDA DE PROBLEMAS
═════════════════════════════════════════════════════════════════════════════

PROBLEMA: Arquivo .exe não abre
SOLUÇÃO:
   1. Verificar se é arquivo correto
   2. Clicar 2x (não 1x)
   3. Aguardar 10 segundos
   4. Se não abrir, compatibilidade pode ser o problema


PROBLEMA: Erro "BASE_PEDIDOS não encontrada"
SOLUÇÃO:
   1. Abrir Excel original
   2. Verificar nome da aba
   3. Aba se chama "BASE_PEDIDOS"?
   4. Se não, renomear para "BASE_PEDIDOS"


PROBLEMA: Nenhum duplicado encontrado (quero verificar)
SOLUÇÃO:
   1. Realmente não há duplicados (é normal)
   2. App mostra mensagem especial: "NENHUMA DUPLICATA ENCONTRADA"
   3. Isso significa que dados estão limpos!


PROBLEMA: Coluna R não aparece na seleção
SOLUÇÃO:
   1. Sua coluna pode não se chamar "R"
   2. Renomear para R, NF, NUMERO_NF
   3. Recarregar arquivo
   4. Coluna deve aparecer
